# Logo oficial UDES

Coloque aquí el archivo **oficial** del logo de la Universidad de Santander, con uno de estos nombres:

- `logo-udes.svg` (preferido), o
- `logo-udes.png` (fondo transparente, mínimo 256 px de alto)

La aplicación lo carga automáticamente en la barra superior. Mientras no exista, muestra un espacio reservado con el texto «LOGO UDES».

No recree ni redibuje el logo: use únicamente el archivo entregado por la universidad, según su Manual de Marca (la tipografía Aachen BT es exclusiva del logo).
